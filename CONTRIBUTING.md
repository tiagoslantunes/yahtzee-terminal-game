# Contributing

Contributions that improve correctness, tests, accessibility, or terminal usability are welcome.

1. Create a branch from `main`.
2. Keep game rules in `yahtzee.py` and interface changes in `main.py`.
3. Add or update tests for rule changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining the behavior change.

Please avoid committing generated files, editor settings, or unrelated refactors.
